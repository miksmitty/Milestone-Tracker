Quick update shows just RAG and dates: click a RAG to change it, or edit a date. Switch to All fields to change titles, lanes, links and the rest. Click a column header to sort, use the filter row to narrow the list, and drag a header edge to resize (double-click to reset). ID is the primary key: assigned automatically, never changes or gets reused, and is what links between items point at. Ref is your own label (e.g. 4.1). Data is stored in milestones.csv next to the server — edit it in a spreadsheet if you prefer, then hit Reload. An item whose start is before its end is a task (bar); set start = end for a milestone (changing a milestone's end date moves it; set an earlier start to turn it into a task). Changing an end date shifts everything that depends on it by the same amount.

Click a report to view or edit it. Sort, filter and resize columns as on the Items tab. To report on an item, click it on the Gantt chart and choose Provide report, or use Report… on the Items tab. Reports are stored in reports.csv, one row per report, linked to the item by its ID.
