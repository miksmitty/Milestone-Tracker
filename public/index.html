Click a column header to sort, use the filter row to narrow the list, and drag a header edge to resize (double-click to reset). ID is the primary key: assigned automatically, never changes or gets reused, and is what links between items point at. Ref is your own label (e.g. 4.1). Data is stored in milestones.csv next to the server — edit it in a spreadsheet if you prefer, then hit Reload. An item whose start is before its end is a task (bar); set start = end for a milestone (changing a milestone's end date moves it; set an earlier start to turn it into a task). Changing an end date shifts everything that depends on it by the same amount.
