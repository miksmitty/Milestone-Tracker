Changes save automatically

Quick update shows the fields that change most — ref, title, type, owner, RAG and dates: click a RAG to change it, or edit any cell. Switch to All fields for lanes, links, shape and the rest. Tick the boxes on the left (shift-click for a range, or the header box for everything shown) to change a field on many rows at once, move their dates, or delete them. Click a column header to sort, use the filter row to narrow the list, and drag a header edge to resize (double-click to reset). ID is the primary key: assigned automatically, never changes or gets reused, and is what links between items point at. Ref is your own label (e.g. 4.1). Data is stored in milestones.csv next to the server — edit it in a spreadsheet if you prefer, then hit Reload. Type says whether something is a milestone (one date, drawn as a shape: changing either date moves it) or a task (a start and end, drawn as a bar). Change the type to give a milestone a date range, or to collapse a task to one date. Changing an end date shifts everything that depends on it by the same amount.

Due lists what still needs a report this period, by owner: anything that has started or already has reports, until it reaches a done status. Each follows the cadence of its latest report (weekly if it has none), and a report whose period reaches into the current one covers it. Periods missed counts the periods since its last report.

Select a report to read it in the preview, and use ↑ ↓ to move through the list. Click into the preview to edit the report. Sort, filter and resize columns as on the Items tab. To report on something, click it on the Gantt chart and choose Provide report, or use Report… on the Items tab. Reports are stored in reports.csv, one row per report, linked to what it covers by its ID.
